Accessibility statement

How we try to make StateDocuments.com usable, and how to report a problem.

Effective date: November 17, 2026.

StateDocuments.com aims to be usable by as many people as possible, including people who use keyboards, screen readers, or browser zoom.

What we do today

The site is a static set of HTML pages with a modest style sheet and a small script that runs only in your browser. Current features include:

  • A “Skip to main content” link at the top of every page
  • Page language set to English
  • Headings, navigation, main content, and footer marked up with standard HTML
  • Labels on menus, breadcrumbs, and the unofficial-site disclosure
  • A mobile menu button that reports whether it is open
  • Keyboard use of the state jump menu, list filters, and sortable tables
  • A reduced-motion style when your device asks for it
  • No auto-playing media and no third-party widgets

We have not completed a formal accessibility audit, and we do not claim that every page meets a particular technical standard.

Known limits

Some official government sites we link to may be harder to use than this site. We do not control those sites. A few of our comparison tables are wide and may require scrolling on a small screen.

Contact

If you have trouble using this site, or if you want to report an accessibility barrier, please check back here. A contact email will be added to this page soon.

If this changes

If we add email signups, analytics, or other features, we will review this statement and update it before those features go live.
